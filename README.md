# Зал

Журнал тренировок на телефон и компьютер. Сейчас на главном экране календарь и колечки шагов. Живёт на GitHub Pages и Firebase, без установки из магазина.

Google-вход пока не нужен: кто откроет ссылку, увидит те же дни и цель.

## Как пользоваться

1. Откройте сайт в браузере.
2. Тап по дню выбирает его. Тап по строке «Шаги» — записать число за этот день.
3. Потяните календарь вниз или нажмите серую ручку — откроется месяц. Колечко заполняется как шаги / цель.
4. Сердечко — избранные тренировки: выбрать вид и добавить в день.
5. Шестерёнка — цель шагов в день (по умолчанию 8000).

На телефоне: Chrome (Android) или Safari (iPhone) → «На экран Домой».

## Сделать свой журнал

Нужны бесплатные аккаунты GitHub и Google. Платный тариф Firebase не нужен — хватает Spark.

### 1. Репозиторий

1. Скопируйте файлы в новый **публичный** репозиторий.
2. GitHub → **Settings → Pages → Deploy from a branch** → ветка `main`, папка `/`.
3. Сайт будет по адресу `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`.

### 2. Firebase

1. [console.firebase.google.com](https://console.firebase.google.com) → новый проект (не путайте с покупками).
2. Добавьте веб-приложение, скопируйте `firebaseConfig` в `index.html` вместо пустого блока.
3. **Build → Realtime Database → Create** → регион `europe-west1` (или любой, главное чтобы `databaseURL` совпал).
4. Вставьте правила из `database.rules.json` и нажмите **Publish**.

В `index.html` идентификатор журнала, 8–32 латинских буквы или цифры:

```js
const JOURNAL_ID = "zalsteps01";
```

Пока `firebaseConfig` пустой, всё хранится только в браузере этого устройства. После подстановки ключей дни и цель одинаковые на телефоне и компьютере.

| Файл | Зачем |
